# Pruebas Unitarias - Luz de Plata

## Herramientas utilizadas

Para las pruebas unitarias del frontend se utilizaron:

- Jasmine
- Karma
- ChromeHeadless

Jasmine se utilizó para definir y estructurar las pruebas unitarias.

Karma se utilizó para ejecutar las pruebas automáticamente en un navegador.

ChromeHeadless permitió ejecutar las pruebas sin necesidad de abrir manualmente una ventana del navegador.

---

## Comando de ejecución

Las pruebas se ejecutan desde la terminal con:

```bash
npm test
```
