# Luz de Plata - Tienda online académica

Proyecto frontend desarrollado con **HTML5, CSS externo y JavaScript puro**. La persistencia se realiza con **localStorage** para cumplir el alcance de la Evaluación Parcial 1 de DSY1104.

## Cómo ejecutar

1. Abre la carpeta `luz-de-plata` en VS Code.
2. Recomendado: ejecuta `index.html` con la extensión **Live Server**. También puede abrirse directamente, pero un servidor local entrega un comportamiento más consistente de localStorage.
3. Navega desde el menú.

## Funciones incluidas

- Home con video local, productos destacados y footer.
- Catálogo dinámico desde un arreglo persistido en localStorage.
- Filtros, búsqueda, detalle de producto, favoritos y carrito.
- Registro, inicio de sesión y roles.
- Validaciones JavaScript con mensajes personalizados.
- Formulario de contacto.
- Compra simulada, historial de compras y envíos.
- Administrador con CRUD de productos y usuarios.
- Región/comuna dependientes.
- Diseño responsivo.
